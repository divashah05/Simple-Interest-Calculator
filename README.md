# Simple Interest Calculator

A simple, responsive web application that calculates simple interest and the total amount using the principal, annual interest rate, and time period entered by the user.

## Features

- Accepts principal amount, annual interest rate, and time in years
- Calculates simple interest
- Calculates the final amount (principal + interest)
- Displays values in Indian Rupees (INR)
- Includes input validation and a reset button
- Responsive layout for mobile and desktop screens

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

**Total Amount = Principal + Simple Interest**

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Enter the principal amount, annual interest rate, and time in years.
5. Click **Calculate Interest** to view the result.

## Example

For a principal of ₹10,000, an annual interest rate of 5%, and a time period of 2 years:

- Simple Interest = (10000 × 5 × 2) / 100 = ₹1,000
- Total Amount = ₹10,000 + ₹1,000 = ₹11,000
